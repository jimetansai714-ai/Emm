01 · Application Scope

App Overview

eMMC List is a dedicated technical hardware reference and memory chip (eMMC/UFS) specification lookup tool built for mobile repair technicians and hardware engineers. The application provides integrated IC part numbers, pinout references, density configurations, and device compatibility specifications.

The application is engineered to operate reliably in both offline and online environments, enabling repair technicians to query local cached hardware specifications at the workbench while synchronizing updated memory chip reference tables when an internet connection is available.

02 · Zero Identity Profiling

No Account Registration Required

eMMC List does not require or offer user account registration, sign-up forms, password logins, personal names, email addresses, or user profiles to access its technical reference functions.

You can launch and use the application without submitting any personally identifiable information (PII) or linking any external social or cloud identity provider.

03 · Technical Installation Identifier

App-Scoped Device UUID (EMMC-...)

Upon initial installation, the application generates a random, app-scoped installation identifier formatted with the prefix EMMC-... (UUID). This identifier is stored locally within the application's private sandbox storage on your Android device.

The app-scoped UUID is used solely for:

  • Configuration synchronization and reference catalog version checks.
  • Offline and online database access verification.
  • Technical authorization pairing for extended specification tables.
Strict Hardware & Personal Privacy Guarantee: eMMC List explicitly does NOT collect, read, transmit, or access hardware IMEI numbers, device serial numbers, MAC addresses, SIM card or phone numbers, address book contacts, photos/media files, or GPS/precise location data.
04 · Technical Database Authorization

Access Key & Authorization Token

eMMC List includes standard hardware lookup specifications and supports technical token verification for extended memory chip reference datasets:

Extended database features are unlocked using an authorized Access Key / Activation Token issued by the developer and paired with your installation UUID.

When an authorized Access Key / Activation Token is entered into the application, the app verifies the token against the app-scoped EMMC-... installation UUID over an encrypted HTTPS connection (`TLS 1.3`) and caches the verification state locally so that extended reference tables remain accessible during offline repair sessions.

06 · User Control & Right to Erasure

Data Retention & Deletion

You retain full control over the locally stored database cache and your app-scoped installation UUID at all times:

  • Local Data Reset & Removal: You can permanently delete all locally stored specification caches, configuration preferences, and reset your app-scoped EMMC-... UUID at any time by clearing the application data in your Android system settings (Settings → Apps → eMMC List → Storage → Clear Data) or by uninstalling the application.
  • Revoking a Paired UUID Record: If you have paired your installation UUID with an authorized Access Key / Activation Token and wish to permanently revoke or delete the paired UUID association from our authorization records, simply contact the developer using any of the support channels below with your EMMC-... identifier. Requests are processed promptly within 48 hours.
